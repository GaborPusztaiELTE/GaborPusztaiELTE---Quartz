## 1. ipconfig / ifconfig

Megmutatja a számítógép hálózati interfészeinek IP-címét, alhálózati maszkját, alapértelmezett átjáróját.

Példa:

ipconfig

## 2. nslookup

DNS lekérdezésekhez használható. Megmondja, hogy egy domain névhez melyik IP cím tartozik (vagy fordítva).

Rekord típusai: 

A- ipv4, AAAA - ipv6, MX - mailserver, NS - nameserver

Példa:

nslookup www.google.com

## 3. ping

Ellenőrzi, hogy egy host elérhető-e a hálózaton, és méri a válaszidőt.

ICMP Echo Request csomagokat küld a célhoz, és méri a visszaérkező Echo Reply-k válaszidejét.

Példa:

ping www.google.com  
ping -n 5 8.8.8.8 # 5 csomagot küld (Windows)  
ping -c 5 8.8.8.8 # Linux/macOS verzió

## 4. tracert (Linux alatt: traceroute)

Megmutatja, hogy milyen útvonalon (routereken keresztül) jut el a csomag a célhoz.

Fokozatosan növeli az IP-csomagok TTL értékét, így minden útvonalon lévő router visszaküldi a saját címét, mielőtt a célállomást eléri.

Példa:

tracert www.google.com
